# StudySmart

StudySmart combines the supplied Assignment 1 pages with the Assignment 2 Services, Portfolio, and Contact pages. It uses a student study-planner theme and loads study photographs directly from Unsplash instead of storing personal computer images in the project.

## Pages

- `index.html` — Home page with a study photograph and links to every page.
- `media.html` — Study dashboard plus the media and information requirements: image, video, audio, ordered and unordered lists, and a data table.
- `register.html` — Profile form with text, password, email, date, URL, color, number, time, range, textarea, select, file, radio, and checkbox controls. It also demonstrates required, read-only, disabled, min/max, min/max length, checked, and selected attributes.
- `services.html` — Flexbox service cards with online images, hover transforms, and transitions.
- `portfolio.html` — CSS Grid gallery with keyframe animation and responsive breakpoints.
- `contact.html` — About section and contact form with live character count and browser-side validation.

Each page has a separate stylesheet in `css/`. Small DOM interactions are in `js/contact.js` and `js/register.js`.

## Run locally

Open this folder in Visual Studio Code and run `index.html` with Live Server. Internet access is needed for Unsplash photographs, Google Fonts, the existing Assignment 1 Bootstrap stylesheet, and sample audio/video resources.

## Image and media sources

- Home, Services, and Portfolio photographs: Unsplash source links are included beside the images.
- Rain audio: Wikimedia Commons, `Rain.ogg` (public domain).
- Sample video: MDN interactive examples media.

## Scope

This is a front-end prototype. Planner tasks and progress values are examples. The profile form does not create an account. The contact form checks fields in the browser but does not send or store messages.
